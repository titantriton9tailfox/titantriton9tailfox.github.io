## Overview

This repository hosts **7 interactive, browser-based prototypes** demonstrating **human-in-the-loop AI workflow automation**, **nonprofit and veteran service readiness**, **CIS Linux hardening**, **zero-trust cloud infrastructure-as-code (IaC)**, and **enterprise AI prompt governance**.

Every application is engineered around **Anthropic's 4D AI Fluency Framework** (*Delegation, Description, Discernment, and Diligence*), enforcing strict PII/PHI redaction rules, zero hardcoded secrets, and mandatory human sign-off gates before high-stakes operational execution.

## Architecture & Human-in-the-Loop Methodology

* **AI-Assisted Engineering with Human Verification:** Prototypes were architected, iteratively refined, and verified using **Claude** alongside manual security, syntax, and domain-logic testing.
* **Privacy-by-Design:** All tools run 100% client-side in standalone HTML/React/Tailwind CSS with zero external API calls, zero telemetry, and zero client PII/PHI storage.
* **Operational Accountability:** Every workflow embeds explicit transparency banners and human sign-off checklists to prevent unverified AI outputs from reaching production systems.
